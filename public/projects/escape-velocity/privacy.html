Privacy Policy

Escape Velocity · Effective date: 2026-11-23

The iOS app: Escape Velocity: Sol

The iOS and iPadOS app Escape Velocity: Sol collects no personal data. Nothing you do in the app is sent to us or to anyone else.

  • No accounts: there is nothing to sign up for or log in to.
  • No ads.
  • No analytics and no tracking of any kind.
  • No third-party SDKs.

Your progress stays on your device. It is saved in the app's own storage, and it is included in your own device backups (for example iCloud or computer backups) only if you have turned those backups on. We never see it. Deleting the app deletes the saved progress on that device.

The web version at bilko.run

The free web version of Escape Velocity, played in a browser at bilko.run, works differently from the iOS app:

  • It sends anonymous gameplay telemetry to bilko.run: screen views and run results (for example which planet a run reached, whether it was won, how long it lasted and which ship class was used), plus similar game events such as tutorial steps, boss fights and in-game shop purchases made with in-game credits. These events contain no personal data: no names, email addresses or account ids. bilko.run groups them by an anonymous visitor and session id kept in a cookie, so we can see how many runs reach each planet.
  • Cloud saves are only for signed-in bilko.run players: if you are signed in to bilko.run, your save is also stored in the cloud on bilko.run so you can continue in another browser. If you are not signed in, the save stays in your browser's local storage only.

None of this applies to the iOS app, which sends nothing.

Children

Because the iOS app collects no personal data at all, it collects none from children either.
