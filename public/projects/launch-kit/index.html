How it works

Four steps to lift-off.

  1. 01

    Install

    Drop the skill folders into ~/.claude/skills/ or your project's .claude/skills/.

  2. 02

    Run launch-context

    Five minutes of questions. It writes .launch/context.md, which every other skill reads.

  3. 03

    Fire the skills

    Page, headlines, pricing, emails, launch week, posts, first 100. Each writes its own file.

  4. 04

    Read the scorecard

    A 0–100 launch readiness score tells you what's still red before you push the button.

FAQ

Questions, answered.

What is a Claude skill?

A folder with a SKILL.md file: plain-text instructions Claude loads when your request matches. There is nothing to compile or install beyond copying the folder.

Which Claude products does it work with?

Claude Code, Claude.ai (upload each skill as a zip in Settings → Skills) and the Agent SDK. Claude.ai can't write to your disk, so it hands you each output to save yourself.

What do I get?

A zip with the eight skills, a README and licence files. Each purchase includes 20 downloads, and you can re-download any time by signing in with your purchase email.

What about refunds?

Not useful to you? Contact us via https://bilko.run/contact within 14 days and we'll refund you.

Does it phone home?

No. The skills contain no telemetry. They read and write files in your own .launch/ folder and that's it.

Will it write things I can publish blind?

It drafts. You edit and ship. Check every claim and number before it goes out.
