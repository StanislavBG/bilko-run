Bilko

The host platform behind bilko.run. Every tool is an independent app that borrows Bilko's auth, credits, component kit and brand chrome. Bilko itself is the framework, not a product.

Who it's for

Visitors

People using the AI tools, games and courses published under bilko.run, plus the blog and projects portfolio.

Sibling-app builders

Claude sessions working in sibling repos under ~/Projects/. They register and publish apps through the bilko-host MCP and the host-kit SDK.

The operator

Admin pages for analytics, cost, secrets, comp grants and observability.

Key features

Static-path hosting contract

Sibling apps are published into public/projects/<slug>/ and served at /projects/<slug>/. The spec is in docs/host-contract.md. Three host kinds: react-route, static-path, external-url.

Project registry

Schema-validated registry (src/data/standalone-projects.json, 27 entries today). It feeds the home page, /projects and ⌘K.

Shared auth & credits

Clerk JWT auth, Stripe token credits and one-time purchase tiers, and a shared wallet across tools.

AI-tool gateway

Gemini-backed scoring endpoints in server/routes/tools/ for StackAudit, LaunchGrader, AdScorer, HeadlineGrader, ThreadGrader, EmailForge, AudienceDecoder and PageRoast.

host-kit SDK

packages/host-kit/: authFetch/useAuth, games hooks, SiteHeader, GameShell and the bilko-host-kit manifest CLI.

bilko-host MCP

mcp-host-server/ exposes register, publish, status, list and unregister tools for static projects, with publish gates.

Shared component kit

src/components/tool-page/: ToolHero, ScoreCard, SectionBreakdown, CompareLayout, Rewrites, CrossPromo.

Blog, analytics, ops

Blog CRUD, page-view and event analytics, telemetry beacons, a synthetic monitor, cost monitor and sanity-QA scripts.

Session Manager surfaces

Landing page, field manual, relay (server/sm-relay/) and project-feedback API. These are sanctioned app-specific host code.

Tech stack

TypeScript. React 18 + Vite 6 + Tailwind v4 on the front end; Fastify 5 + Turso/libSQL (local SQLite fallback in dev) on the back end; Clerk; Stripe; Gemini REST. Deployed on Render from StanislavBG/bilko-run main. Package manager: pnpm 10; Node ≥18.

How to run

pnpm install
pnpm dev          # Vite client + tsx-watched Fastify server
pnpm build        # vite build + tsc server
pnpm start        # node dist-server/server/index.js

Env vars (Clerk, Stripe, Gemini, Turso) are managed in the Render dashboard; dev falls back to local SQLite.

Ground rules

Push to origin (StanislavBG/bilko-run) main only. Each tool stays independent. New apps default to static-path in their own repo. SQL is always parameterized. Token-spending endpoints require requireAuth. Paid-tier entitlement comes only from the verified Clerk token. Any change to mcp-host-server/src needs a rebuilt, committed dist/.
